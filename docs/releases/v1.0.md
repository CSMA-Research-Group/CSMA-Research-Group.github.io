# CSMA Research Group v1.0

The first formal release of the approved English-language CSMA Research Group website. The Git release tag is `v1.0`; the npm package version is `1.0.0`.

## Website structure

Home, News, Research, Projects, Publications, People, Resources, and About form the primary navigation. Home presents the welcome and research vision, News, publications beside projects, four research directions, members, resources, and joining information.

- Publications, systems, members, and Research Insights have individual introduction pages.
- News and former members have dedicated archives.
- Resources separates Research Applications, Research Insights, and the group's GitHub entry.
- The founding date is July 20, 2022.

## Included in this release

- The approved layout, typography, colors, cards, and link placement across the homepage and detail pages.
- Four research directions: Cognitive and Collaborative Intelligence, Intelligent Software Engineering, Intelligent Robotics, and Application Scenarios.
- Confirmed publication metadata and supporting CMCS, TraceCoder, SemFaith, and ChatREQ resources, including supplied architecture diagrams.
- Six confirmed members using default avatars, with research areas and profile pages.
- A shared research illustration with slow orbit rings, particles, accessible hotspots, and reduced-motion support.
- A brighter visitor globe with solar illumination, occasional meteors, four rotating world-city clocks, and a translucent single-line local clock. A visible meteor can trigger a five-second notice.
- Research Insights articles on REA and MASS, with primary sources and a clear separation between source-reported findings and group perspectives.

## Validation and local use

```bash
npm ci
npm test
npm run build
npm run dev
```

The production build is written to `dist/`. Use `npm run preview` to inspect it locally. GitHub Pages builds and deploys the source on pushes to `main`; this release does not change or deploy the visitor-statistics Worker.

## Information still to be supplied

All current members use the shared default avatar. Blank optional fields remain blank until confirmed.

The release also includes the corresponding public assets, tests, generated site, and maintenance documentation.
