# CSMA Research Group v2.0

Released on October 24, 2026. The Git tag is `v2.0`; the npm package version is `2.0.0`.

This release adds a complete Simplified Chinese edition and refines how the website presents the group's research, members, and collaboration opportunities. Both languages share the same confirmed publications, projects, people, statuses, and links.

## Included in this release

- Complete bilingual coverage: 29 English pages and 29 Chinese counterparts, including publications, systems, member profiles, Research Insights, and archives.
- A fuller Chinese academic homepage with research questions, actual method figures, publication-linked systems, ongoing projects, and member introductions. English content and destinations remain aligned; the two layouts need not be identical.
- Larger, consistent Chinese sans-serif typography, responsive layouts, breadcrumbs, research-area member filters, and Chinese reading titles alongside original publication titles.
- An unboxed language icon with English / 简体中文 options, current-language indication, keyboard support, and preservation of the current page, query parameters, and anchor.
- A Chinese research illustration with interactive research links and an accessible image viewer supporting fit-to-screen and original-size inspection.
- Research vision centered on cognitive and collaborative intelligence, connecting individual cognition, multi-agent and cross-model collaboration, human-AI collaboration, and practical applications.
- A shared invitation to worldwide partners from universities, research institutions, and industry for joint research, academic exchange, and application exploration.
- Email and social contact icons that retain real link destinations without displaying email addresses or account handles. Institutional affiliation wording is removed from the group and lead-member presentation and search metadata.
- Eight confirmed members with supplied portraits; shared publication links and SemFaith's Accepted status remain consistent across languages.
- Chinese labels for the existing visitor globe, country names, world clocks, and statistics. The visitor service, data model, and display offsets are unchanged.

## Page structure

Both languages use Home, News, Research, Projects, Publications, People, Resources, and About as the primary navigation. Detail pages cover five systems, four publications, eight members, and two Research Insights articles; News and Alumni have archives. Routes use hash navigation: English starts at `/#/`, Chinese at `/#/zh`.

The Chinese homepage presents the group introduction, research progress, research questions, publications and systems, ongoing projects, Research Insights, members, and collaboration opportunities. See the [bilingual maintenance guide](../bilingual-content.md) for the complete route mapping.

## Validation and local use

```bash
npm ci
npm test
npm run build
npm run dev
```

The 32 automated checks include server rendering of all 58 bilingual pages, translation coverage, internal navigation and anchor alignment, member photos and email links, publication identity, and accepted status. The release was also reviewed in a browser for language switching, desktop and mobile layout, contact icons, and image-viewer interaction.

The production build is written to `dist/`, which is tracked with the source. Use `npm run preview` to inspect it locally. Pushing `main` triggers the existing GitHub Pages workflow; the `v2.0` tag identifies this release. This release does not deploy or modify the visitor-statistics Worker.
