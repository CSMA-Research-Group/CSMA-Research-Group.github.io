## 语言行为

- 语言图标入口始终可见，手机导航收起时也可使用。
- 站内链接沿用当前语言；共享的邮箱、DOI、GitHub 和下载地址不随语言改写。
- 明确访问 `/#/`、英文详情或中文详情时，地址中的语言优先。
- 导航使用语言图标按钮，展开后提供 `English` 和 `简体中文`，当前语言显示勾选。切换保留当前页面、查询参数和栏目锚点。支持键盘操作、Escape 关闭并归还焦点，点击外部或移出焦点时关闭；语言面板与手机导航互斥。
- 仅在直接打开不带 hash 的站点地址时，使用 `csma-language` 保存的上次主动选择。未选择或浏览器禁用存储时默认英文，不根据地区或浏览器语言强制跳转。
- 文档 `lang`、页面标题及描述随路由更新；中文采用 `zh-CN`。

## 内容边界

- 正式论文题名、作者顺序、会议名称、年份、DOI 与研究结果数值保持原样。中文版另附中文阅读题名，不将其视为官方出版题名。
- 已确认的成员英文姓名保持原样。尚未提供的中文姓名不按拼音猜写；照片、邮箱和论文关联共用原记录。
- SemFaith 的 Accepted 显示为“已录用”，由同一状态字段产生，成员页与论文页一致。
- 原始论文图、PDF 和代码资料继续保留原文；网页图注和替代文字翻译为中文。首页和研究页的愿景图提供完整中文插画；首页使用紧凑呈现并提供整页栏目导航，研究页保留图下的方向导航；小屏可通过“查看大图”阅读全部图内标签。
- 项目题名中的 `[MASK]` 保留；项目状态、学生正在开展的工作、论文检查器局限和研究洞见的来源边界不因翻译而升级为已完成成果。
- REA 文章仍说明未独立运行或评测；MASS 的结果仍归于原作者，保留迁移收益不一致和两轮实验的限制。

## 本地审阅与检查

```sh
npm ci
VITE_VISITOR_API_BASE= npm run dev -- --host 127.0.0.1 --port 5197
```

打开 `http://127.0.0.1:5197/#/zh`。本地关闭访客 API 时显示“暂不可用”，不填充模拟访问量；正常生产构建沿用 `.env.production` 的访客服务配置。

```sh
npm test
npm run build
git diff --check
```

双语检查通过服务端渲染覆盖全部 58 个页面，核对路由、中文内部链接、未翻译文案、成员照片与邮箱、正式论文元数据和录用状态。它不能替代浏览器检查：仍需检查桌面和手机排版、折叠菜单、语言图标菜单切换、刷新、裸入口的语言记忆，以及带查询参数和页内锚点的详情链接。图片查看器需确认放大后的左右边缘均可滚动到达、键盘焦点限制在弹窗内、关闭后恢复焦点和页面滚动。

`dist/` 为受 Git 跟踪的构建产物，随源代码重建。构建通过后由用户审阅；不自动提交、推送或部署。
