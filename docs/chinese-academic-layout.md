- 研究定位、方向、论文题名、作者、年份、录用或发表状态、项目关联、成员身份、照片、邮箱、机构和联系方式共用 `src/data/` 的记录。
- 中文摘要、研究说明、成员简介和图注继续通过 `src/i18n/zh/` 翻译已有正文。首页和成员目录可以选取摘要，完整介绍仍在对应详情页。
- 中文可以调整栏目顺序、内容密度和图文布局。英文首页继续使用原有版式，中文首页由 `ChineseHome.vue` 呈现；双方使用同一批真实研究记录。
- 品牌和机构展示位置尽可能与英文保持一致：导航和首页首屏不额外添加机构标识；机构信息只在英文也有的相应位置呈现。
- 中文首页和资源页的页内锚点同时存在于对应英文页面。切换语言保留当前页面与栏目；不能为了新增中文导航而制造没有英文对应位置的链接。
- 方法图使用已有论文图，保留原图文字与中文图注。ChatREQ 使用的图明确标为 KGMAF 框架图；图不作为在线产品界面或演示截图。
