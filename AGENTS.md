# AGENTS.md

## Project
This repository hosts the official website of CSMA Research Group, deployed through GitHub Pages.

## Goal
Improve the website into a professional research-group homepage comparable to websites from world-class university labs and research institutions.

## Technical Stack
- Vue 3
- Vite
- JavaScript
- CSS
- GitHub Pages

## Working Rules
- Do not delete the Git history.
- Do not remove existing source files unless clearly obsolete and replaced.
- Do not invent real publications, real awards, real grants, real members, or institutional affiliations.
- Use placeholder entries when real data is missing.
- Prefer structured data files for people, publications, projects, research areas, and news.
- Keep the site easy to maintain.
- Ensure `npm run build` succeeds before finishing.
- Do not commit or push automatically. The user will review and push manually.

## Design Direction
The website should feel like a serious academic research group homepage:
- clean
- modern
- credible
- research-oriented
- visually restrained
- responsive
- suitable for AI, software engineering, multi-agent systems, cognitive intelligence, and embodied intelligence research.

## Content Direction
The website should emphasize:
- cognitive intelligence
- multi-agent systems
- intelligent software engineering
- intelligent requirements engineering
- code generation, debugging, and repair
- knowledge-guided reasoning
- embodied and robotic intelligence
- trustworthy AI systems

## Output Requirements
At the end, provide:
1. Summary of changed files.
2. New page structure.
3. How to run locally.
4. How to build.
5. Any placeholders that still require real information.
